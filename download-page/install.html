安装帮助

码伴 PixelPal 当前是 Beta 测试版，尚未完成正式代码签名和公证。系统提示未知开发者、阻止打开或安全提醒时，通常不是文件损坏，而是 Beta 阶段的正常限制。

macOS

下载后先解压 zip，再把应用拖到“应用程序”文件夹。

如果提示无法打开或来自未知开发者，可以打开“系统设置”里的“隐私与安全性”，在安全提示附近选择仍要打开。

如果仍打不开，请把系统版本和提示截图发给测试组织者。

Windows

下载后运行安装包。如果出现 Windows Defender SmartScreen 提示，可以点“更多信息”，再选择“仍要运行”。

如果杀毒软件拦截，请先不要强行关闭安全软件，把拦截图发给测试组织者。

打不开时请反馈

请提供电脑系统、下载的文件名、点击后的提示截图，以及是否能重新下载。这样可以更快判断是下载问题、系统权限问题还是安装包问题。
