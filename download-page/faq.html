常见问题

为什么系统提示未知开发者？

当前版本仍是 Beta 测试版，尚未完成正式代码签名和公证。正式商用前会优先处理签名和公证，减少系统安全提示。

它会读取我的聊天或文件吗？

不会。码伴 PixelPal 只会尝试识别当前前台应用名称或窗口标题，用来切换桌宠状态，不读取文件内容、聊天内容或浏览器历史。

DeepSeek Key 是必须的吗？

不是。没有 Key 也可以使用桌宠、提醒、贴边和快捷指令。只有使用轻量问答时，才需要你主动填写自己的 DeepSeek API Key。

为什么它没有识别某个软件？

Beta 阶段只覆盖常见办公、写代码和视频场景。未识别的软件可以通过反馈方式告诉我们，后续版本会逐步补充。

可以商用吗？

当前版本适合公开试用和小范围付费试用。正式公开商用前，还需要完成签名、公证、更多稳定性测试和更明确的售后说明。
