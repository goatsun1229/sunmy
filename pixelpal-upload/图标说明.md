# 码伴 PixelPal 图标说明

当前已生成：

- `build/icon.png`

图标是原创像素风：暖白色编程小伙伴、深色屏幕脸、小眼镜、键盘和顶部小气泡。

当前 Electron Builder 已配置使用：

- `build.icon = build/icon.png`

macOS `.icns` 暂未生成成功，本机 `iconutil` 对 iconset 报 `Invalid Iconset`，但 PNG 图标可先用于 Beta 包和 Windows 转换。

正式发布前建议：

1. 用设计工具导出 `icon.icns`。
2. 用设计工具导出 `icon.ico`。
3. 放到 `build/icon.icns` 和 `build/icon.ico`。
4. 保持 `build/icon.png` 作为通用源图。
