常见问题

为什么系统提示未知开发者？

当前版本尚未完成正式代码签名和系统公证。后续会优先处理签名和公证，减少系统安全提示。

它会读取我的聊天或文件吗？

不会。码伴 PixelPal 只会尝试识别当前前台应用名称或窗口标题，用来切换桌宠状态，不读取文件内容、聊天内容或浏览器历史。

DeepSeek Key 是必须的吗？

不是。没有 Key 也可以使用桌宠、提醒、贴边和快捷指令。只有使用轻量问答时，才需要你主动填写自己的 DeepSeek API Key。

为什么它没有识别某个软件？

当前版本优先覆盖常见办公、写代码和视频场景。未识别的软件可以通过反馈方式告诉我们，后续版本会逐步补充。

可以商用吗？

可以。当前版本已开放下载和购买，后续会继续补齐签名、公证、稳定性优化和更完整的售后说明。
